# scoop-symbiote

Scoop bucket for the **Symbiote CLI** (`symbiote`) on Windows.

```powershell
scoop bucket add symbiote https://github.com/symbiote-labs/scoop-symbiote
scoop install symbiote
```

The `bucket/symbiote.json` manifest is published automatically by the release
pipeline; it points at the binaries in
[symbiote-cli-dist releases](https://github.com/symbiote-labs/symbiote-cli-dist/releases).
